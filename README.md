# Nexus AI — LLM-Powered ML Workflow Orchestration Platform

An AI-powered ML workflow platform that converts natural language prompts into executable machine learning pipelines using Llama3, FastAPI, and React.

---

## 🚀 Features

- AI-generated ML pipelines
- CSV dataset upload
- LLM-powered workflow orchestration
- Dynamic pipeline execution
- Interactive workflow visualization
- Automated preprocessing
- Random Forest model training
- Download trained models and processed datasets

## ⚙️ Workflow

1. Upload CSV dataset  
2. Enter ML intent  
3. Dataset profiling  
4. LLM generates ML pipeline  
5. Pipeline validation  
6. Dynamic execution  
7. Model + artifact generation
